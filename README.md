## Features

- Hacker style boot screen with opening shutters
- Name decode effect and typing roles
- Animated radar and live SOC alert ticker
- Red code rain background, cursor glow and scroll progress bar
- Scroll reveal animations and 3D tilt on cards
- Responsive design for mobile and desktop

## Tech stack

HTML, CSS and JavaScript. No frameworks and no build step.
